<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FTP endpoint→local filesystem | Remote server-controlled paths and metadata are materialized onto the local disk. |
| configured destination root→actual writes | Every local write must stay under the caller-approved root. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | T | FTP→local path joins | mitigate | Normalize and verify every local target path remains under `Destination.LocalPath`; reject or fail the operation rather than writing to cwd or escaping the root. |
| T-06-03-02 | D | destination-root creation | mitigate | Auto-create only the explicit configured root per D-08; never infer `.` or a missing path as an acceptable fallback. |
| T-06-03-03 | I | local filesystem writes | mitigate | Reuse the existing FTP pull path’s metadata and write behavior, but add public regression tests to prove writes stay within the configured root. |
| T-06-03-04 | R | cwd safety regression | mitigate | Add a public API test that changes cwd and asserts no synced files appear there unless cwd is the configured local root. |
</threat_model>
