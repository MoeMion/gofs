<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local disk→FTP server | File contents and paths cross from caller-controlled local filesystem to remote FTP endpoint. |
| FTP server→local disk | Remote listing and file paths cross into local filesystem writes. |
| caller options→network dial | Host, credentials, passive mode, timeout, and encoding configure outbound FTP connections. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | T | FTP→local path mapping | mitigate | Preserve `ensureTargetUnderRoot` and test `NeverWritesToCWD`; reject paths escaping configured destination root. |
| T-08-02-02 | I | error/log hooks | mitigate | Continue using `newTransferError` and compact hook payloads that do not include FTP passwords. |
| T-08-02-03 | D | retry helper | mitigate | Retry count is bounded by `RetryOptions.Count`, waits respect context cancellation, and timers are stopped. |
| T-08-02-04 | S | FTP authentication | transfer | Plain FTP auth remains server-handled per v1 scope; this phase preserves typed credential use and does not add FTPS. |
</threat_model>
