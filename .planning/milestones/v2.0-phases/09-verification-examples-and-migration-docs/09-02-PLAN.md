<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Test process → loopback FTP server | Tests authenticate to a local server over TCP. |
| Local temp filesystem → FTP server root | Test files cross protocol boundary into fixture storage. |
| FTP server root → local temp filesystem | Test files cross protocol boundary back into local destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Spoofing | FTP fixture auth | mitigate | Use fixed test-only credentials and bind server to `127.0.0.1`; no external accounts. |
| T-09-02-02 | Tampering | Test fixture filesystem | mitigate | Serve only `t.TempDir()` roots and assert exact expected file contents. |
| T-09-02-03 | Information Disclosure | FTP credentials | mitigate | Use test-only credentials; never print `FTPOptions` structs containing passwords on failure. |
| T-09-02-04 | Denial of Service | Network listener | mitigate | Use loopback-only listener, per-test cleanup with `server.Stop()`, and `Timeout: 5 * time.Second`. |
| T-09-02-05 | Elevation of Privilege | FTP server mode | mitigate | Keep all server fixture code in `_test.go`; no production FTP server API or exported package surface. |
</threat_model>
