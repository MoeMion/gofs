<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem→FTP driver | Local files and symlinks are transferred to a remote FTP endpoint. |
| library hooks→caller code | `ftpsync` invokes caller-provided synchronous callbacks during one-shot execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-01 | T | local walker sequencing | mitigate | Reuse the existing create/write/symlink sequencing from `diskSync.syncWalk` so the library orchestrator does not invent new FTP mutation semantics. |
| T-06-02-02 | I | hook/event payloads | mitigate | Emit only operation/path/status/error-kind and summary counts; never include FTP password values or full per-file report bodies. |
| T-06-02-03 | D | best-effort loop | mitigate | Continue after per-path failures while bounding work to the explicit source root only; aggregate failures instead of retrying unboundedly inside the loop. |
| T-06-02-04 | R | summary accuracy | mitigate | Increment compact counts from the same walk that drives mutations so callers can correlate partial failure with attempted work. |
</threat_model>
